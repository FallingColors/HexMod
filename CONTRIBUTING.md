## General notes

- Test your changes to make sure everything actually works before submitting a PR
- Each PR should generally address one issue or introduce one feature (a set of closely related issues/features is OK)
- Make sure that your PR targets the correct branch (`main` for the 1.20.1 version of the mod, `1.21` for 1.21.1)
- Make sure to add a new line to the [changelog](CHANGELOG.md) describing the changes you made and linking to your PR
- When adding/changing ingame text, no need to include versions in other languages unless you're fluent
